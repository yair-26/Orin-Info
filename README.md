# ORIN INFO

סוכן קולי בעברית דרך טלפון, שעונה על שאלות ומחפש מידע באינטרנט בשם המשתמש. אבטיפוס.

## איפה מתחילים
1. docs/PRODUCT.md – מה בונים ומה נחשב הצלחה.
2. docs/STATUS.md – מה קיים, מה נשאר, ומה דורש בן אדם.
3. docs/TASKS.md – המשימות הבאות.
4. docs/DEPLOYMENT.md – איך עולים לאוויר בחינם ועובדים שניים במקביל.
5. docs/FIRST_SESSION_PROMPT.md – ההודעה לפתיחת הסשן הראשון ב-Claude Code.

## מבנה
core/ – ליבת הקול והסוכן (אביאל)
products/info/ – ההתנהגות הספציפית ל-INFO (אביאל)
admin/ – דשבורד ניהול (יאיר), כולל mock-data
config/ – ספקים, מחירים, תקרות
scripts/ – דוח עלות, מבחן שאלות
docs/ – אפיון, מצב, החלטות, חוזה API
tests/

cp .env.example .env   # ממלאים מפתחות רק ב-.env
