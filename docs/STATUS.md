## דורש בן אדם (Claude Code לא יכול לבצע)
- בחירת מסגרת קול ובחינתה בפועל (אביאל).
- פתיחת חשבונות ומפתחות אצל ספקים, ותקרות הוצאה בכל חשבון.
- בירור מול 3–4 ספקי טלפוניה, מספר בדיקה, ובדיקת נגישות מ-5–6 מכשירים כשרים.
- הקשבה לאיכות העברית (STT ו-TTS) והקלטות אמיתיות דרך טלפון.
- מילוי config/pricing.yaml ממחירי ספקים עדכניים עם מקור ותאריך.
- גורם תורני, מדיניות תוכן, ייעוץ משפטי ומדיניות פרטיות ושמירה.
- איסוף שאלות אמיתיות מראיונות (קבוצת הערכה של 50 שאלות).
- גיוס משתמשי ניסוי וניסוי בפועל.
- הכרעות פתוחות ב-docs/decisions.md.
- חשבון GitHub משותף, והרשמה לשירות אירוח ומסד נתונים חינמיים (אחרי בדיקת תנאים עדכניים).

## חסימות ידועות
- אין עדיין ספק טלפוניה או מסגרת קול נבחרים.
- לא ידוע אם מספר מתקשר מועבר ממכשירים כשרים (משפיע על D-003).

## שערים
ש1 (סוף שבוע 1): ספק מתאים ושיחת טקסט עובדת. ש2: איכות עברית ונגישות. ש3: שיחה ראשונה מהטלפון. ש4: הסוכן עונה על שלושת סוגי הבקשות. ש5: עלות לדקה ידועה ודשבורד על נתונים אמיתיים. ש6: ממשיכים, משנים או עוצרים. פירוט בתוכנית האבטיפוס.
